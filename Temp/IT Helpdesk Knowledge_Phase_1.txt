Knowledge Base: IT Helpdesk Knowledge

Overview:
The IT Helpdesk Knowledge Base provides technical support guidance, troubleshooting procedures, and service request information for employees and support teams. The objective is to reduce resolution times and enable users to solve common IT issues through self-service assistance.

Common Troubleshooting Steps:

Password Reset:
1. Navigate to the password self-service portal.
2. Verify identity using MFA.
3. Create a new password following company policy.
4. Sign in again using the updated credentials.

VPN Connectivity Issues:
1. Verify internet connectivity.
2. Ensure VPN client is installed and updated.
3. Confirm account permissions.
4. Reconnect using approved VPN credentials.
5. Contact IT Support if the issue persists.

Outlook Not Sending Emails:
1. Verify internet connection.
2. Check mailbox quota.
3. Restart Outlook.
4. Confirm account settings.
5. Recreate Outlook profile if required.

Support Priority Levels:

Priority 1:
Critical business outage affecting multiple users.

Priority 2:
Major functionality impacted with no workaround.

Priority 3:
Single-user issue with workaround available.

Priority 4:
General requests, information inquiries, or low-impact issues.
